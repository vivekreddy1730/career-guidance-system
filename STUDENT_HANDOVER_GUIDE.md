## 💻 2. Local Setup (Running on Your Own Laptop / Lab PC)

If your external examiners require running on `localhost` without an internet connection:

### Prerequisites:
* Python 3.10 or higher
* Node.js 18 or higher

### 🚀 1-Click Execution:
1. **First-time Setup:** Double-click **`setup.bat`** in the project root. This automatically installs all Python packages and Node dependencies.
2. **Launch Application:** Double-click **`start.bat`**. This opens both backend and frontend servers in separate windows.

* Navigate to **Assessment**.

  2. *Domain & Coding Knowledge*
  3. *Problem Solving & Logic*
  4. *Workplace Personality & Soft Skills*

* Upload a PDF or paste plain resume text.

### Step 5: Interactive Learning Roadmaps & AI Interviewer
* Open **Career Roadmap** to show phase-by-phase learning milestones with interactive checkboxes.
